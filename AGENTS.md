# Documentation project instructions

## About this project

- This is a Mintlify documentation site for Keystone Commerce.
- Pages are MDX files with YAML frontmatter.
- Configuration lives in `docs.json`.
- Run `mint dev` to preview locally.
- Run `mint broken-links` before publishing.

## Style

- Use active voice and concise sentences.
- Write for external partners.
- Do not document internal admin APIs unless explicitly requested.
- Keep endpoint examples copy-pasteable.
