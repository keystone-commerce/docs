---
title: "Customers"
description: "Customer profile and address APIs"
---

Profile and address endpoints require a Customer access token. They do not require `x-partner-id` because the token identifies the customer.

```http
Authorization: Bearer <access_token>
```

## Get profile

| Method | Endpoint | Auth |
| --- | --- | --- |
| `GET` | `/users/me` | Customer access token |

Request:

```bash
curl https://dev-api.keystonecommerce.in/api/v1/users/me \
  -H "Authorization: Bearer <access_token>"
```

Response:

```json
{
  "statusCode": 200,
  "message": "Success",
  "data": {
    "id": "cmr928qjc000002s6nh2ufmo2",
    "partnerId": "<partner_id>",
    "phone": "<customer_phone>",
    "name": "<customer_name>",
    "email": "<customer_email>",
    "role": "USER",
    "addresses": []
  }
}
```

## Update profile

| Method | Endpoint | Auth |
| --- | --- | --- |
| `PATCH` | `/users/me` | Customer access token |

Request:

```bash
curl -X PATCH https://dev-api.keystonecommerce.in/api/v1/users/me \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"<customer_name>","email":"<customer_email>"}'
```

Response:

```json
{
  "statusCode": 200,
  "message": "Success",
  "data": {
    "id": "cmr928qjc000002s6nh2ufmo2",
    "partnerId": "<partner_id>",
    "phone": "<customer_phone>",
    "name": "<customer_name>",
    "email": "<customer_email>",
    "role": "USER"
  }
}
```

## Create address

| Method | Endpoint | Auth |
| --- | --- | --- |
| `POST` | `/users/me/addresses` | Customer access token |

Request:

```bash
curl -X POST https://dev-api.keystonecommerce.in/api/v1/users/me/addresses \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "recipientName": "Aarav Sharma",
    "recipientPhone": "9876543210",
    "label": "Home",
    "line1": "221B MG Road",
    "line2": "Near Trinity Metro",
    "city": "Bengaluru",
    "state": "Karnataka",
    "pincode": "560001",
    "isDefault": true
  }'
```

Response:

```json
{
  "statusCode": 201,
  "message": "Success",
  "data": {
    "id": "cmr928qzz000202s6f59zezkm",
    "recipientName": "Aarav Sharma",
```
